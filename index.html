❓ Aide VOLTCORE

Comment créer une facture ?

Facturation → "+ Nouveau document" → remplis le client, ajoute des lignes, vérifie les totaux, puis "Enregistrer".

Comment ajouter un client ?

Clients → "+ Nouveau client" → nom obligatoire, le reste optionnel.

Comment scanner un document ?

Outils → Scanner → autorise la caméra → capture → ajuste les coins → "Appliquer" → "Documents".

Comment faire un avoir ?

Facturation → clique sur la facture → "Créer avoir". Les lignes sont pré-remplies, ajuste les quantités puis enregistre.

Comment faire une sauvegarde ?

Outils → "Exporter (JSON)". Un backup automatique est fait chaque jour dans IndexedDB (7 derniers).

Comment restaurer ?

Outils → "Importer un backup" → tape FUSIONNER pour ajouter, ou REMPLACER pour tout écraser (dangereux).

Comment activer le mode sombre ?

Outils → Paramètres → bascule "Mode sombre".

Comment libérer la garantie BTP ?

Ouvre une facture en garantie → clic "🔓 Libérer garantie" → saisis le montant → confirme.

Comment activer la biométrie ?

Paramètres → bouton "Empreinte" sur l'écran de connexion (nécessite HTTPS).

Raccourcis clavier

Échap = fermer la modale du dessus. Ctrl+K = focus recherche. Ctrl+S = sauvegarder.
